# تعريب مونلايتر | Moonlighter Arabic
تعريب مجتمعي غير رسمي للعبة Moonlighter على Windows Steam، مع مثبّت وخيار خط البكسل أو الخط العادي.
## التحميل والتثبيت
حمّل ملف `Moonlighter-Arabic-Public.zip` الموجود في هذا المستودع، وفك الضغط كاملًا. أغلق اللعبة ثم شغّل `MoonlighterArabicSetup.exe`، وحدد مجلد اللعبة واختر الخط واضغط «تثبيت / تحديث».
شغّل اللعبة من Steam واختر English لعرض العربية.
النسخة المدعومة: Steam 1.15.8، البناء 16760112. يتضمن المثبّت التحقق من الملفات والنسخ الأصلية وخيار إزالة التعريب.
الإصدار 0.3.0 — معاينة مجتمعية. لم تُختبر جميع المشاهد والحوارات والدقات. لا تتضمن الحزمة ملفات اللعبة الأصلية؛ يلزم امتلاك اللعبة.

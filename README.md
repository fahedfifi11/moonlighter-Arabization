# تعريب مونلايتر | Moonlighter Arabic

تعريب مجتمعي غير رسمي للعبة Moonlighter على Windows Steam، مع مثبّت وخيار خط البكسل أو الخط العادي.

## تحميل التعريب

**[اضغط هنا لتحميل ملف التعريب المضغوط](https://github.com/fahedfifi11/moonlighter-Arabization/releases/download/v0.3.0/Moonlighter-Arabic-Public.zip)**

[صفحة الإصدار وتعليماته](https://github.com/fahedfifi11/moonlighter-Arabization/releases/tag/v0.3.0)

## التثبيت

1. حمّل `Moonlighter-Arabic-Public.zip` من الرابط أعلاه، وفك الضغط كاملًا.
2. أغلق اللعبة ثم شغّل `MoonlighterArabicSetup.exe`.
3. حدد مجلد اللعبة واختر الخط واضغط «تثبيت / تحديث».
4. ادخل على اللعبة من ستيم.
.
النسخة المدعومة: Steam 1.15.8، البناء 16760112. يتضمن المثبّت التحقق من الملفات والنسخ الأصلية وخيار إزالة التعريب.

الإصدار 0.3.0 — معاينة مجتمعية. لم تُختبر جميع المشاهد والحوارات والدقات. لا تتضمن الحزمة ملفات اللعبة الأصلية؛ يلزم امتلاك اللعبة.
